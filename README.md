# Знаки Кингисеппа

Карта дорожных знаков поверх спутника Кингисеппа. Полосами вдоль бордюра показаны зоны действия
знаков 3.27 «Остановка запрещена», 3.28 «Стоянка запрещена», 5.15.1 «Движение по полосам»
(со стрелками по каждой полосе) и 3.24 «Ограничение скорости» (цветная полоса с цифрой).
Каждый тип включается и выключается отдельно, есть фильтр по значению скорости и по знакам,
действующим только в определённые часы/дни.

## Что уже есть

- Спутник Esri World Imagery (без ключа) + прозрачный слой подписей улиц.
- Здания: 2305 контуров из OpenStreetMap (data/buildings.js) рисуются лёгким псевдо-3D
  «эскизом» (светлая крыша + тёмный выступ на северо-восток, размер по этажности),
  чтобы карта не выглядела плоской. Включаются галочкой «здания (3D-эскиз)»,
  показываются с зума 14. Данные сняты 2026-10-28.
- Дорожная сеть города (520 участков, ~133 км) — знак рисуется точно вдоль улицы:
  клик в начале, клик в конце, участок сам прокладывается по дорогам.
- Отрисовка: полоса вдоль бордюра (смещение 3,2 м от осевой — остаётся на асфальте, а не над
  газоном), шевроны направления, стрелки по полосам, кружки со скоростью, бейдж номера знака,
  пометка «⏱» у знаков с ограничением по времени.
- Значки не наезжают друг на друга: на экране они раскладываются жадно, а слипшиеся сворачиваются
  в один со счётчиком «+N» — клик по нему приближает карту. У каждого значка подпись с названием
  улицы (галочка «названия улиц у значков», появляются с зума 16); подписи, которым не хватило
  места, скрываются, чтобы не налезать друг на друга.
- Оформление — тёмно-фиолетовая тема: градиентные кнопки с плавными переходами и откликом на нажатие,
  стеклянные панели, крупные чекбоксы; на телефоне панель выезжает снизу листом.
- Карточка знака: тип, улица, длина, сторона, время действия, автор, кнопки «Изменить»/«Удалить».
- Панель панорам Яндекс.Карт (нужен ключ) — проверять знаки, не переключая вкладку.
- Кнопка «Яндекс ↗» — открывает это же место на спутнике Яндекса, где снимки Кингисеппа заметно чётче, чем на Esri.
- Два режима хранения: локальный (браузер + экспорт/импорт JSON) и онлайн через Supabase.
- Значки на карте — миниатюры настоящих знаков по ГОСТ: 3.27 (крест), 3.28 (одна диагональ),
  3.24 (круг с цифрой), 5.15.1 (синий прямоугольник со стрелками по полосам).
- Панорама показывает те же полосы прямо поверх кадра: полоса лежит на дороге, у начала виден сам
  знак и его протяжённость. Кнопки «←» и «→» шагают по улице на 16 м.
- Админ-режим: пароль один раз вводится в сайдбаре, после этого можно удалять любые участки.
  Без пароля посетитель удаляет только то, что нарисовал сам.
- Общая база: правки сразу видны всем, у всех свежие данные подтягиваются автоматически раз в 30 секунд
  (и при возврате на вкладку). Кнопка «↻ Обновить» рядом с часами синхронизации — вручную.
- Свои участки удаляются сразу, чужие — только в админ-режиме: клик по полосе → «Удалить».
- Устанавливается как приложение (PWA): манифест, иконки, service worker, офлайн-кеш оболочки.
- Телефон: панель управления — выдвижной лист снизу (кнопка «☰» вверху слева, закрывается
  свайпом-тапом по карте или по затемнению), карта занимает весь экран, кнопки крупные под палец;
  панорама на телефоне тоже разворачивается на весь экран.
- Работает и по `file://` (двойной клик по `index.html`), и на GitHub Pages.

## Где это живёт и когда работает

Сайт — обычная статика на GitHub Pages, данные — в Supabase. И то и другое работает круглосуточно
на серверах GitHub и Supabase: чтобы друзья открыли карту, твой компьютер и открытый GitHub
не нужны. Нужен только интернет.

- **Сайт:** https://kyz1kss.github.io/kingmapznaki/
- **Правки:** пишутся в общую базу Supabase, поэтому их видят все, у кого есть ссылка.
- **Локальный сервер** (`python -m http.server 8765`) нужен только для предпросмотра на своём
  компьютере: он ничего не публикует и на работу сайта в интернете не влияет.

## Что уже занесено

На момент последнего обновления в базе 50 участков (46 занесено с панорам и OSM, 4 добавили посетители):

- 17 × 3.27 «Остановка запрещена» — Воровского, Октябрьская, Иванова, Б. Советская, Железнодорожная,
  К. Маркса и перекрёстки в центре (у большинства на столбе табличка «эвакуатор»);
- 4 × 3.28 «Стоянка запрещена» — Иванова, Октябрьская (включая участок, нарисованный вручную);
- 5 × 5.15.1 «Движение по полосам» — Воровского и К. Маркса (2 и 3 полосы, стрелки по каждой);
- 20 × 3.24 «Ограничение скорости» — 17 зон из OpenStreetMap (20, 40, 70, 80 км/ч) и 3 участка с панорам.

Знаки искались автоматически по кадрам панорам: детектор красной каймы (круглые знаки) и синего
поля (5.15.1), затем каждый кандидат просматривался глазами и заносился в базу с привязкой к улице.

Запрещающие знаки прочитаны по панорамам Яндекса и помечены в карточке как «по панораме, проверить»:
мелкие таблички на снимках иногда не читаются, поэтому такие участки стоит сверять глазами.
Покрытие пока неполное: разобраны центральные улицы (Иванова, Воровского, Октябрьская, Б. Советская,
часть К. Маркса), остальной город нужно добивать — либо через редактор на сайте, либо новым проходом
по панорамам.

## Админ-режим (один раз)

Прямое удаление в таблице закрыто, удаляет серверная функция с проверкой прав.
Чтобы включить админа:

1. Supabase → **SQL Editor → New query** → вставить [`supabase-admin.sql`](supabase-admin.sql).
2. В строке `digest('CHANGE_ME', 'sha256')` заменить `CHANGE_ME` на свой пароль
   (файл лежит в публичном репозитории, поэтому настоящий пароль туда не пишем).
3. **Run**. Затем на сайте: сайдбар → «Админ» → ввести пароль → «Войти».

После этого в карточке любого знака кнопка «Удалить» станет активной. У остальных посетителей
она активна только для участков, которые они нарисовали сами (браузер помнит их `owner_token`).
Пароль хранится в браузере, чтобы не вводить его каждый раз; «Выйти из админ-режима» его стирает.

Сменить пароль позже:

```sql
update public.app_secrets
   set value = encode(digest('новый-пароль', 'sha256'), 'hex')
 where key = 'admin_hash';
```

## Панорама с наложением

Кнопка «Панорама» открывает кадр Яндекс.Карт, а поверх него рисуются наши знаки: у плеера
спрашиваются точка съёмки, азимут и наклон взгляда и угол обзора, каждая точка полосы
переводится в экранные координаты. Если панорама не открывается и пишет про лимит —
у ключа закончился бесплатный дневной лимит запросов, это ограничение Яндекса, а не сайта;
ссылка «Открыть панораму в Яндекс.Картах» работает всегда (обычная страница Яндекса в новой вкладке).
Автоматически «ходить» по панорамам из скрипта сейчас нельзя: и API-ключ исчерпывает лимит, и
сам yandex.ru режет автоматические запросы (429). Поэтому новые знаки добираем либо глазами
через «Открыть панораму», либо редактором прямо на карте — правки идут в общую базу на всех.

## Быстрый старт

```bash
# просто открыть index.html в браузере — уже работает
# либо поднять локально, если удобнее:
python -m http.server 8765
# http://127.0.0.1:8765/index.html?demo=1  — с шестью примерами на центральных улицах
```

`?demo=1` заливает примеры только в локальном режиме и только если база пустая.
Чтобы убрать демо: «Экспорт» не нужен, достаточно очистить данные браузера для этой страницы.

## 1. Публикация на GitHub Pages

1. Создай пустой репозиторий, например `kingisepp-signs`.
2. Залей папку проекта:
   ```bash
   git init
   git add .
   git commit -m "Знаки Кингисеппа: первая версия"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_НИК/kingisepp-signs.git
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
   Workflow `.github/workflows/pages.yml` уже лежит в проекте, он соберёт сайт при каждом пуше.
4. Через минуту сайт будет на `https://ТВОЙ_НИК.github.io/kingisepp-signs/`.

## 2. Общая база (Supabase, бесплатно)

Нужна, чтобы правки видели все, а не только ты.

1. Регистрация на [supabase.com](https://supabase.com) → **New project** (регион — ближайший, бесплатного тарифа хватает).
2. **SQL Editor → New query** → вставь содержимое [`supabase.sql`](supabase.sql) → **Run**.
3. **Project Settings → API**: скопируй `Project URL` и `anon public` ключ.
4. Впиши их в [`assets/js/config.js`](assets/js/config.js):
   ```js
   supabase: {
     url: 'https://xxxxx.supabase.co',
     anonKey: 'eyJhbGciOi...',   // или sb_publishable_... для новых проектов
     table: 'signs'
   },
   ```
5. Перезагрузи сайт — в шапке появится «Онлайн: правки сохраняются в общей базе».

По умолчанию в политиках RLS писать может любой, у кого есть ссылка на сайт (проект для друзей).
Если нужна авторизация — включи Supabase Auth и замени `true` в политиках на `auth.role() = 'authenticated'`
(подсказка есть в комментариях `supabase.sql`).

## 3. Панорамы Яндекса в панели

1. [developer.tech.yandex.ru](https://developer.tech.yandex.ru/) → войти с Яндекс-ID.
2. **Подключить API** → «JavaScript API и HTTP Геокодер» → указать домен сайта
   (`твой-ник.github.io` и, для локальных тестов, `localhost`).
3. Ключ появится через ~15 минут. Вставь его в `config.js`:
   ```js
   yandexApiKey: 'твой-ключ',
   ```
4. Обязательно заполни **«Ограничение по HTTP Referer»** в настройках ключа: домен сайта и `localhost`.
   IP-адреса вроде `127.0.0.1` Яндекс не принимает — поле ругается «Некорректное значение».
   Без referer новые ключи отвечают `{"statusCode":403,"message":"Invalid api key"}`.
   Поэтому локально сайт открывай через `http://localhost:8765/`, а не через `127.0.0.1`.
5. Без ключа кнопка «Панорама» всё равно работает — открывает панораму в новой вкладке Яндекс.Карт.

Бесплатный лимит — загрузки карты в сутки при условиях бесплатного использования
(сайт открыт всем, без платного доступа, логотип Яндекса не убирается). По тарифам это до 500 в сутки,
но у конкретного ключа лимит может быть меньше (у нового ключа бывает 100) — смотри в кабинете,
в блоке «Тариф».

## Про подложку

Спутник — Esri World Imagery, без ключа. Над Кингисеппом он старый и мыльный: родной уровень
детализации заканчивается на z17, на z19 Esri вообще отдаёт «Map data not yet available».
Поэтому максимальный зум на сайте ограничен 18 (дальше просто растягивание), а рядом с «Панорамой»
есть кнопка «Яндекс ↗» — она открывает ту же точку на спутнике Яндекса в новой вкладке.

Ключ Tiles API в проекте не используется: в этом API есть только схема (`l=map`), спутника и
гибрида там нет — Яндекс их не отдаёт растром. Ключ оставлен в `config.js` на будущее.
Если понадобится спутник Яндекса прямо в интерфейсе, придётся переводить карту на их JS API целиком.

## Как рисовать участок

1. Кнопка «+ Нарисовать на карте» или клавиша `A`.
2. Клик по улице — начало. Второй клик — конец. Участок прокладывается по дорожной сети,
   а не по прямой; внизу слева показывается улица и длина.
3. В карточке: тип знака, сторона (левая/правая/обе), направление действия,
   скорость, полосы (клик по чипу меняет стрелку: налево → прямо → направо → прямо и налево →
   прямо и направо → разворот), время действия и дни (чётные/нечётные/будни), комментарий.
4. «Сохранить». `Esc` — отмена.

Правка и удаление — клик по полосе на карте, кнопки в карточке.

## Данные

Дорожная сеть выгружена из OpenStreetMap (© участники OSM, лицензия ODbL). В ней 520 участков
улиц города с названиями. Знаки в OSM по Кингисеппу не размечены (0 объектов), поэтому
содержимое карты заполняется вручную — через редактор или панорамы.

Панорамы Яндекса используются только как источник для человека: изображения не скачиваются
и не хранятся, в базу попадает только текстовая информация об участке.
